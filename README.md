## 🎯 Project Overview
This project represents a comprehensive multi-page web application designed to master client-side form creation, styling, and validation. Developed as part of the Front-End Development curriculum at Astana IT University, it bridges the gap between raw HTML5 native validation mechanisms and advanced, responsive UI component styling via **Bootstrap 5.3**. 

The application is structured into a cohesive, responsive interface featuring a shared navigation bar (`navbar`) that links seamlessly across all individual task modules.

---

## 🎓 Learning Objectives
* Understand the core anatomy of HTML forms (`<form>`, `<label>`, `<input>`, `<textarea>`, `<select>`, `<button>`).
* Implement native **HTML5 validation attributes** (`required`, `type="email"`, `minlength`, `maxlength`).
* Leverage **Bootstrap 5 grid system** (`row`, `col-md-*`, `g-3`) to build fully responsive form layouts.
* Utilize Bootstrap **validation feedback classes** (`is-valid`, `is-invalid`, `.valid-feedback`, `.invalid-feedback`) paired with custom JavaScript event listeners to control submission states.
